# D.A.A.R.U

Sistema autónomo de detección de acumulación de residuos urbanos utilizando visión por computadora y machine learning.

## Cómo usarlo

1. Instalar las dependencias con `pip install -r requirements.txt`
2. Poner el dataset en la carpeta `datos/`
3. Entrenar con `python entrenar.py`
4. Detectar con `python detectar.py`
